Yoean Support

技术支持

这里提供钥安的常见问题与问题反馈入口。为了保护你的隐私，请不要在反馈中发送密码、银行卡信息、恢复码或备份文件。

Help center

常见问题

  • 忘记恢复码怎么办？
    恢复码无法由开发者找回。请妥善保管恢复码，并与加密备份文件分开保存。
  • 更换设备或生物识别设置后无法解锁？
    使用此前导出的加密备份和对应恢复码，在新设备上恢复保险库。
  • 关闭 iCloud 安全同步会删除云端副本吗？
    不会。关闭同步只停止此设备后续的上传与下载；已有云端密文不会因此删除。
  • 删除本机保险库会删除备份或其他设备的数据吗？
    不会。已导出的备份文件和其他设备上的副本需分别管理。

Contact

联系与反馈

可通过 GitHub 仓库提交问题：打开问题反馈页。

GitHub 问题可能公开显示。请只描述操作步骤、设备型号和 iOS 版本；不要提交任何保险库内容、个人信息、密码、恢复码或备份文件。涉及账户或隐私的问题，请勿在公开页面披露敏感信息。

Privacy

关于数据与安全

钥安不要求注册账号，也不向开发者服务器上传保险库明文。你主动开启安全同步时，应用层加密后的内容会存入你自己的 iCloud 私有数据库。加密备份由你选择保存位置。

完整隐私说明请查看 App 内“设置 → 隐私政策”。
